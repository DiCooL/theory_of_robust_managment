# Эксперименты на гироскопическом стенде с дроном

Документы по подготовке стенда к экспериментам: прошивка платы LDM-BB-K1986BE92QI, запись телеметрии, питание, беспроводной канал через Raspberry Pi. Составлено по ходу работы 17–24 ноября 2026 года.

| Файл | Что внутри |
|---|---|
| `01_plan.md` | Пошаговый план от прошивки до экспериментов, отметки выполнения, журнал |
| `02_quickstart.md` | Краткая инструкция: как прошить плату, запустить дрон с пульта, записать и проверить лог |
| `03_hardware.md` | Устройство стенда: питание, моторы, геометрия, разъёмы платы |
| `04_raspberry_pi_telemetry.md` | Как подключиться к Raspberry Pi и записывать лог по Wi-Fi |
| `05_firmware_changes.md` | Что и зачем изменено в прошивке стенда (защиты) |
| `06_chronology.md` | Хронология этапов и результатов проверок |
| `tools/stand_logger.py` | Запись телеметрии платы в CSV (работает и на Windows, и на Raspberry Pi) |
| `tools/check_response.py` | Проверка знака реакции моторов по CSV-логу |

Исходники прошивки в эту папку не входят: прошивка стенда ведётся в общем репозитории коллег `Epinephrine20mg/stand_uav`.
