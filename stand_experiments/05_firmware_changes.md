# Что изменено в прошивке стенда

За основу взята прошивка `maxim's intercept` из общего репозитория стенда (коллега Максим): регулятор ведёт крен по записанной траектории 0 → +20° → 0 → −21° → 0, шаг 0.317 с, длительность 45 с, пока канал 5 пульта выше 1900. Закон: `F = (−0.7·(α−α_d) − 0.4·(ω−ω_d))/0.16`, перевод силы в ШИМ по таблице `Esc_mx` (диапазон ШИМ 1110–1490). Изменён только файл регулятора `vcontroller.cpp`:

- **Зависание в `BinSearch`.** Если нужная сила выходила за таблицу, поиск зацикливался, и моторы оставались на последнем ШИМ. На модели для компьютера оригинал зависает, например, при крене −40° и скорости −400°/с. Теперь значение ограничивается границей таблицы.
- **Отключение при |крен| > 45°.** Моторы выключаются; повторный запуск возможен только после опускания и подъёма канала 5.
- **Конец траектории.** После 45 с моторы выключаются и ждут опускания канала 5. Каждый новый подъём канала 5 начинает траекторию с начала (в оригинале счётчики не сбрасывались).
- **Интерполяция ШИМ по таблице.** Исправлены веса: базовый ШИМ сместился на несколько единиц (раньше 1187/1172/1187/1167, теперь около 1182/1177/1181/1159).

Все изменения проверены на модели для компьютера и на стенде без винтов (отключение по 45° срабатывает, повторный запуск работает, направление реакции моторов верное). Работа с винтами не проверялась.

Не изменено: failsafe приёмника (приёмник держит последнее значение канала 5 при потере связи).
