# Быстрый старт: прошивка, запуск, запись лога

## Если нужна прошивка (только после правки кода)

1. В Keil открыть проект прошивки и нажать F7. Ожидается `0 Error(s)`.
2. Подключить USB в разъём X1 платы (порт COM9, мост CP2102) и запустить утилиту 1986WSD. В поле файла выбрать собранный `vimana.hex`.
3. Перевести плату в режим загрузчика: зажать SA3 (BOOT), нажать и отпустить SA1 (PWR OFF), отпустить SA3. Нажать Start, после Program/Verify нажать RUN.
4. Закрыть 1986WSD (он занимает COM-порт).

Если пишет «ошибка синхронизации»: проверить положение SA3, закрыть программы, занимающие COM9, проверить номер порта в Диспетчере устройств, понизить скорость до 57600, прошивать при питании только от USB (аккумулятор отключён).

Прошивка нужна только после изменения кода: программа стартует сама при подаче питания.

## Запуск дрона с пульта и запись лога (кабель к ноутбуку)

1. Подать питание на плату (аккумулятор, USB или оба сразу — одновременное подключение проверено, безопасно). Раму держать неподвижно 15–20 секунд: задержка и калибровка гироскопа.
2. В cmd запустить логгер:

```
python D:\download\copter\uav_stand_kit\tools\stand_logger.py --port COM9 --duration 50 --every 1
```

3. Включить пульт и поднять канал 5 выше 1900: моторы включаются, плата 45 секунд ведёт крен по траектории. Опустить канал 5 — моторы выключаются, новый подъём запускает траекторию заново. При |крене| > 45° моторы отключаются, для повторного запуска канал 5 опускают и поднимают.
4. Логгер сам завершается через 50 секунд. Файл: `tools\logs\stand_ГГГГММДД_ЧЧММСС.csv`. В cmd значения печатаются раз в секунду, в файл пишутся все кадры (около 820–870 в секунду).
5. Проверка отклика: `python D:\download\copter\uav_stand_kit\tools\check_response.py` (по умолчанию берёт последний лог). С винтами добавить `--props`.

Python запускается командой `python`, не `py`.

## Формат телеметрии

Кадр 66 байт, заголовок `0x42 0x40`, затем 31 слово little-endian, контрольная сумма `0xFFFF − сумма первых 64 байт`. Поля: время платы (мкс), крен, тангаж, рыскание (°×100), гироскоп (°/с×100), ускорения (×10000), ШИМ четырёх моторов (esc1–esc4). Скорость UART 921600 бод.
